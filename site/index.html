Run it on your own machine

The scraping can run here rather than on a server. It is usually faster, it costs nothing, and job boards that block datacenter addresses — Indeed and Internshala among them — answer a home connection normally.

One command

macOS or Linux. Installs into ~/automated-scraping, needs no admin rights, and is safe to run again to update.

Piping anything into a shell deserves a look first. Read the script — it clones the repository, makes a Python virtual environment, installs the dependencies and checks they import.

Then start it

cd ~/automated-scraping && ./start_dashboard.sh

Opens at http://127.0.0.1:5000 — the same panels as here, plus a Run tab that streams each task's log live as it goes.

What it needs from you: a password

No Google credentials, no key file. The pipeline reads its keywords and settings from this project's service and sends what it finds back the same way, so the only thing your machine needs is the password you signed in with.

export SETTINGS_WEB_APP_URL='…'
export PROJECT_PASSWORD='your project password'

./.venv/bin/python main.py --config config.yaml

There is deliberately no key to hand out: one service-account key can read and write every spreadsheet it has ever been shared with, and there is no way to narrow it to a single project. A password reaches this project and nothing else — and you can change it from Settings whenever you like.

Why bother running it here

Indeed and Internshala refuse datacenter addresses — a Cloudflare 403 and a challenge page respectively — so the scheduled runs skip both. A home connection gets them back.

Use a spreadsheet I already have

The long string in the sheet's URL, between /d/ and /edit. Any missing tabs are added; existing ones are left alone.

It must be shared with the Google account this service runs as — a sheet someone else owns will not open, however well the service account can reach it. Sheets created here are owned by that account already, so this only applies to ones you adopt.

Delete this project

It stops existing here: no password will open it and no run will find it. The Google Sheet is left untouched in Drive.

Asked for again even though you are signed in, so a session left open on a shared machine cannot delete someone's project.
